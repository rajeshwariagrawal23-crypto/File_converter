# Convertly — fixed HTML/CSS/JS edition

## Run locally
1. Extract the ZIP completely.
2. Keep `index.html`, `style.css`, and `app.js` in the same folder.
3. Open `index.html` in Chrome, Safari, Firefox or Edge.
4. To publish, upload the three files to GitHub Pages, Netlify or Vercel as a static website (no build command).

## Supported
PNG/JPG/WEBP output from common browser-readable images (GIF first frame). TXT/MD/HTML/JSON/CSV basic conversions. No server upload.

## Limitations
No PDF, Word, audio or video conversion. BMP is accepted as input where browser-supported but not offered as an output. Text format conversion is simplified and may lose formatting. Maximum 25 MB input and 50 megapixels for images.

## If you still see a blank page
Ensure all three files are extracted to the same folder, rather than opening index.html inside a ZIP viewer. On hosting, check filenames and case sensitivity.
